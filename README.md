# Latentia

**Where images wait to be seen.**  
**萬象未現之境。**

**The AIGC platform of OpenEnvision.**

Latentia 隸屬於 OpenEnvision，關注 AIGC 圖像藝術、AI 微電影與人機共創。我們希望讓值得觀看的作品，連同創造它們的人，一起被看見。

Latentia brings AI image art, short films and human–machine collaboration into view. Discover imagined worlds, meet their creators, and follow each work back to its source.

## 本地查看 / Local preview

直接用瀏覽器打開 `index.html` 即可瀏覽本地作品預覽。影片使用官方在線來源，需要網絡連接。

Open `index.html` in a browser to view the local artwork previews. Films use official online sources and require an internet connection.

也可以在項目目錄運行 / Alternatively, serve this directory locally:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

然後打開 / Then visit [http://127.0.0.1:8000](http://127.0.0.1:8000).
